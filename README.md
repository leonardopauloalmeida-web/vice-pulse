# 🌴 Vice Pulse • GTA VI Hub

Fan site dedicado a **GTA VI**, com contagem regressiva para o lançamento, notícias, personagens, trailers oficiais e o mapa de Leonida.

🔗 **Site no ar:** https://leonardopauloalmeida-web.github.io/vice-pulse/

## ✨ O que o site tem

- ⏳ Contagem regressiva até o lançamento (19 de novembro de 2026)
- 📰 Seção de últimas notícias sobre o jogo
- 🧑‍🤝‍🧑 Página de personagens (Jason e Lucia)
- 🏙️ Página sobre Vice City
- 🎬 Página sobre o diretor
- ▶️ Trailers e gameplay com links para o YouTube
- 🗺️ Mapa de Leonida

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (puro, sem frameworks)
- Hospedagem: GitHub Pages

## 📁 Estrutura do projeto

```
vice-pulse/
├── assets/            # imagens do site
├── index.html         # página inicial
├── personagens.html
├── vice-city.html
├── noticias.html
├── diretor.html
├── style.css          # estilos
└── script.js          # contagem regressiva e interações
```

## ▶️ Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/leonardopauloalmeida-web/vice-pulse.git
   ```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
